# Student Management System

## Project Overview
A Java Swing GUI application to manage student records using a MySQL database.

## Features
- Add student records
- View student details
- Update student information
- Delete student records

## Technologies
- Java
- Java Swing
- MySQL
- JDBC

## Database Table
**students**
- id (Primary Key)
- name
- email
- course
- phone
